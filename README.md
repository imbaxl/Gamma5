# 问芽 · 本地学习笔记

学习交流在本项目聊天窗口进行，网站仅用于笔记记录、档案查看和复盘展示。无需模型 API、密钥或额外模型服务。

## 编辑学习助手提示词

直接编辑项目根目录的 [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md)，可调整讲解方式、录入约定和评分标准。`AGENTS.md` 已要求助手在开展项目任务前读取它。修改后在当前聊天说「重新读取 SYSTEM_PROMPT.md」即可要求加载新内容；这不是网页设置，也不是平台系统级指令的替换。

## 启动程序

需要 Node.js 22 或更新版本。在项目目录运行：

```powershell
npm install
npm start
```

打开 http://127.0.0.1:3210 。以后也可双击 `启动问芽.cmd`，在浏览器打开此地址。

## 正确的工作方式

1. 在本项目聊天窗口上传截图，与助手讨论题目、条件、猜想和推理。
2. 只有明确说「录入这道题」等指令后，助手才整理题目、提问侧重点、条件、推理、发散追问、鼓励与 1–5 分探索评分，并写入本地文件。
3. 网站每 5 秒读取本地文件，切回网页时也会刷新。学习档案可按天查看、搜索、导出，并展示 LaTeX 公式。
4. 网站首页显示科目和章节题量、近七天（含今天）的每日录入题量。点击分类可进入对应题目；在题目详情为这道题补充带日期的笔记。顶部按钮可显示或隐藏侧边栏，并记住选择。
5. 在项目聊天中请求「回顾今天的学习并保存」，助手读取已有记录、整理复盘并保存，网站「每日回顾」显示结果。

网站不读取聊天窗口，也不进行 AI 对话、自动分析或自动评分。讨论及截图本身不触发题目录入。网站上的统计只汇总已经保存的评分，不生成新评分。

## 科目与章节

题目按“数学分析 / 高等代数 → 章节”浏览，章节清单见 `public/categories.js`。聊天录入时必须填写 `category` 和 `subcategory`，规则见 `SYSTEM_PROMPT.md`；记忆卡片也可按章节筛选。手机端使用题目列表和全屏详情，可快速跳到题干、推理和笔记，长公式在内容区域横向滚动。

## 本地文件

- `data/days/YYYY-MM-DD.json`：每日题目、对话摘录、笔记、评分与回顾。
- 截图若能从真实聊天附件获取，以 Base64 放入题目消息的 image 字段；否则助手应保留准确转写并说明截图未归档。
- 备份只需复制 `data/days` 文件夹，网页也支持导出当天 JSON。
- 修改笔记或添加题目后，旧回顾保留并标记待更新。
- LaTeX 支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`；KaTeX 与字体均从本机加载。
- 未保存的笔记离开页面时会提示。程序仅监听本机地址，不向外部模型发送数据。
- 旧版本的 `data/settings.json`（如存在）不再读取或使用。

## 聊天助手录入

详细规则见 `AGENTS.md`。获得明确录入指令后，助手生成临时 JSON 并运行：

```powershell
node scripts/record.js question data/pending-record.json --confirmed
node scripts/record.js review data/pending-review.json --confirmed
```

写入工具直接操作本地文件，即使网页没有启动也能录入。不把开发对话当作学习记录。评分评价探索行为，没有实质提问时不评分。

## 验证

```powershell
npm test
```

测试使用独立临时文件夹，验证聊天助手写入的记录可被网页读取、笔记保存与编辑、已有回顾保留并标记待更新，以及旧的模型接口已移除。
